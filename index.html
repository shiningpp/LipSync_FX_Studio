台词与口型对齐序列

控制语法

台词、口型与差分
写法为 [标签:参数]；标签名使用小写。参数可用英文冒号、中文冒号或逗号分隔；手动口型序列还可用空格。
[rate:150] [pause:500] rate 是后续口型/字符时长（毫秒/字，默认 200）；pause 是停顿时长（毫秒，默认 300）。
[lip:a i u e o m] [auto] lip 只接受 a/i/u/e/o/m，按当前 rate 逐个播放并进入手动模式；auto 恢复台词自动口型。
[eye:Tag] [mouth:Tag] [图层ID:Tag] 切换指定图层的差分；eye/mouth 是眼睛、嘴巴图层别名，其他图层使用英文 ID 或名称。
[var:Tag] 将所有包含该差分 Tag 的图层一起切换到该差分。
眨眼与呼吸
[blink:3:120:300] 眨眼次数:闭眼时长（毫秒）:间隔（毫秒）；闭眼时长默认约为 speed 的 2 倍，间隔默认 180 毫秒。
[blink:speed:60] [blink:interval:2:5] speed 设置闭眼时长（毫秒）；interval 设置最小:最大间隔（秒）。
[blink:on] [blink:off] [blink:open] [blink:half] [blink:close] 分别启用/停用自动眨眼，或固定眼睛为全开、半闭、闭眼；闭眼动作只写 close。
[breath:on] [breath:off] [breath:period:3.5] [breath:reverse:on] 启用/停用呼吸；period 设置周期（秒）；reverse:on 反向（先下后上），reverse:off 恢复默认方向。
[breath:easing:sine] [breath:part:1:0.03:0:sine] 缓动可选 sine/inout/linear/breathe/pulse；part 参数为部位序号(1–5):幅度:相位:缓动。
画面特效
[shake:2:8:12:0.8] [shake:stop] 时长（秒）:幅度:频率:随机度；时长 -1 持续震动，stop 停止；后三项默认 8/12/0.8。
[flash] [flash:350] 闪白时长（毫秒），省略时长默认为 350。
[hue:180] [ca:0.003] 色相偏移（度）与 RGB 分离强度；写 off 可关闭，hue:off 恢复 0。
[crt:4:0.36] [crt:off] 扫描线间距（像素）:强度（0–1）；off 关闭。
[line:on:white:black] [line:off] 线稿开关:线色:填充色；支持 white/black/red/green/blue/yellow 或 #RRGGBB。
[glitch:scan:0.02:8] [glitch:off] 故障类型(scan/slice/rgb):强度:速度；也可用类型编号 0/1/2，off 关闭。
[pixelate:on:4] [pixelate:4] [pixelate:off] 像素化步长（像素，1–64）；off 或 0 关闭，只影响角色画面。
[fisheye:0.3] [screen:0.4] [blur:2] [blur:gaussian:2:4] [blur:radial:0.15:0.5:0.5] [blur:motion:24:0] 鱼眼强度建议 0–1；旧 screen 标签映射为鱼眼；模糊值以像素计，也支持径向（强度:X:Y）和运动（长度:角度）模式。
[brightness:1.2] [contrast:1.1] [saturation:0.7] 亮度、对比度和饱和度倍率；1 为原始值，支持 off 恢复默认。
[temp:0.2] [snow:0.3] [invert:1] 色温建议 -1（冷）至 1（暖）；雪花、反相强度建议 0–1；均支持 off。
[zoom:1.3] [zoom:off] 画面缩放倍率，最低 0.1；off 恢复 1 倍。
图层运动与转场
[move:0.05:-0.02] 角色整体屏幕 UV 的 X:Y 偏移。
[scroll:图层ID:0.05:0] [scroll:off] 指定图层的 X:Y 滚动速度（屏幕 UV/秒）；off 停止滚动。
[rotate:图层ID:30] [rotate:off] 指定图层旋转速度（度/秒）；off 停止旋转。
[fade:in:550] [fade:out:550] 淡入从黑场显露画面；淡出将画面渐隐至黑场，参数为时长（毫秒）。
[wipe:in:left:550] [wipe:out:right:550] 擦除显露/遮黑；方向可选 left/right/top/bottom，参数为时长（毫秒）。
[slide:in:left:550] [slide:out:right:550] 指定图层按方向滑入或滑出；方向为 left/right/top/bottom，参数为时长（毫秒）。旧格式仍可使用。
[boot:550] [shutdown:550] 开机展开/关机收拢，参数为动画时长（毫秒，默认 550）。
标签按台词顺序执行；未匹配到图层/差分的切换命令不生效。只有特效明确列出 off 时才支持该关闭写法；时间单位以各项标注为准。

导入文件准备说明

一键导入（文件夹）

在同一次文件夹选择中包含一个 Spine 风格 JSON 和所有附件 PNG。程序读取第一个 JSON，并只使用 skins.default。

  • JSON 中附件需要有 x、y、width、height 数值，用于计算位置和大小；JSON 的 slots 顺序用于图层排序。
  • 每张 PNG 的文件名（不含扩展名）必须与 JSON 附件名一致，例如 face1.png、mouth1_a.png、eye4_open.png；大小写不敏感。
  • 普通部件用“英文前缀 + 数字”命名；嘴巴帧用 mouth数字_a/i/u/e/o/m；眼睛帧用 eye数字_open/half/close。
  • 扭曲遮罩命名为 hair1_mask_distortion_slotA / hair1_mask_distortion_slotB，按对应差分名绑定；全局遮罩可命名为 mask、global_mask 或 全局遮罩，需有 JSON 附件坐标以正确定位。

此导入方式不读取图层隐藏状态，成功识别的图层都会默认显示；未匹配的附件图片会报告为缺失。

一键导入 PSD

  • 普通部件/差分：前缀数字，如 face1、hair2；相同前缀归为图层，数字作为差分 Tag。
  • 嘴巴帧：mouth5_a，后缀仅接受 a/i/u/e/o/m。
  • 眼睛帧：eye4_open、eye4_half、eye4_close；省略后缀时按全开帧处理。
  • 扭曲用遮罩可命名为 hair1_mask_distortion_slotA / ...slotB；全局遮罩图层名用 mask、global_mask 或“全局遮罩”。

PSD 图层可放在组内，程序会递归读取。隐藏图层也会被导入，识别到的图层导入后默认显示；不想导入的图层请改成不匹配的名称或在导入后手动隐藏。

图层名大小写不敏感；不符合命名规则的图层会被忽略。透明像素会保留。
